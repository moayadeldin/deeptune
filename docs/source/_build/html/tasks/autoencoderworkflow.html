Autoencoder Workflow Components

DeepTune provides dedicated components for image reconstruction using convolutional autoencoders. The workflow supports image preprocessing, model training, evaluation, and reconstructed image generation. This page provides a class-level overview of the autoencoder workflow components.

Model Architecture

Entry point: autoencoders.components.architecture.AutoEncoder

The autoencoder architecture consists of a convolutional encoder, a bottleneck representation, and a decoder that reconstructs the input image.

class autoencoders.components.architecture.ConvBlock(in_ch, out_ch, norm='group', groups=8)

Implements a convolutional processing block consisting of a 2D convolution, optional Group Normalization, and SiLU activation.

Parameters:

  • in_ch – Number of input channels.

  • out_ch – Number of output channels.

  • norm – Normalization type.

  • groups – Maximum number of normalization groups.

class autoencoders.components.architecture.AutoEncoder(use_deeper=False, in_ch=1, base=32, blur_k=5, blur_simga=1.0)

Implements an encoder-decoder architecture for image reconstruction.

Parameters:

  • use_deeper – Whether to use the deeper architecture with additional encoding and decoding blocks.

  • in_ch – Number of input image channels.

  • base – Base number of convolutional feature channels.

  • blur_k – Kernel size of the Gaussian blur operation.

  • blur_simga – Standard deviation of the Gaussian blur.

The encoder progressively downsamples the input image through convolutional blocks, while the decoder reconstructs its spatial dimensions using transposed convolutions.

The default architecture uses three downsampling stages, while the deeper configuration uses five stages.

forward(x)

Applies Gaussian blur to the input image, extracts intermediate representations through the encoder, and reconstructs the image using the decoder.

Returns the reconstructed image and the original unblurred input tensor.

The reconstructed image is passed through a sigmoid activation to constrain its values to [0, 1].

Image Preprocessing

Entry point: autoencoders.components.transforms.apply_transform

autoencoders.components.transforms.apply_transform(image_size, if_grayscale)

Constructs the image preprocessing pipeline.

Parameters:

  • image_size – Target height and width of the image.

  • if_grayscale – Whether to convert images to grayscale.

The pipeline resizes images to square dimensions, optionally converts them to grayscale, and transforms them into PyTorch tensors.

Model Training

Entry point: autoencoders.autoencoder.run_autoencoder

The training workflow initializes the selected autoencoder architecture, prepares image DataLoaders, and optimizes reconstruction using Adam and Smooth L1 Loss.

autoencoders.autoencoder.run_autoencoder(model, train_df_path, transform, test_df_path, num_epochs, learning_rate, out, model_weights=None, device=DEVICE)

Coordinates autoencoder training and evaluation.

Parameters:

  • model – Autoencoder model to train or evaluate.

  • train_df_path – Path to the training Parquet dataset.

  • transform – Image preprocessing transformations.

  • test_df_path – Path to the testing Parquet dataset.

  • num_epochs – Number of training epochs.

  • learning_rate – Learning rate for the Adam optimizer.

  • out – Directory for model and reconstruction outputs.

  • model_weights – Optional path to existing model weights.

  • device – Device used for model execution.

When model_weights is not provided, the function trains the autoencoder by minimizing the Smooth L1 Loss between reconstructed images and original inputs.

When model_weights is provided, the function loads the existing parameters and performs evaluation without additional training.

Model Evaluation

Entry point: autoencoders.autoencoder.test_autoencoder

The evaluation workflow reconstructs images from the testing dataset using the trained autoencoder.

autoencoders.autoencoder.test_autoencoder(model, test_loader, device=DEVICE)

Evaluates the model on the testing dataset without gradient computation.

Returns three lists containing the original target tensors, reconstructed images, and input images.

The current implementation performs reconstruction without computing quantitative evaluation metrics.

Reconstruction Output

Entry point: autoencoders.autoencoder.save_results

The reconstruction workflow generates and organizes reconstructed images according to their corresponding dataset class labels.

autoencoders.autoencoder.save_results(model, out_dir, model_weights, test_loader)

Performs inference on the testing dataset and saves the reconstructed images in class-specific directories.

When training a new model, its parameters are saved as autoencoder_model.pth.

autoencoders.autoencoder.rescale_image(x, eps=1e-6)

Applies channel-wise spatial min-max normalization to rescale reconstructed image tensors to [0, 1] before saving them.

The reconstruction workflow produces the following output directory structure:

output_directory/
└── reconstructed_images_<yymmdd>/
    ├── autoencoder_model.pth
    ├── Class 0/
    │   ├── reconstructed_0.png
    │   └── reconstructed_1.png
    └── Class 1/
        ├── reconstructed_0.png
        └── reconstructed_1.png

The model checkpoint is generated only when training a new autoencoder. Existing checkpoints are not saved again during evaluation-only execution.
